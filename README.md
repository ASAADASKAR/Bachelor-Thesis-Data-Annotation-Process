# CVAT Development – Bachelor Thesis

This repository contains the development work related to my bachelor thesis
on improving a data annotation process using the open-source CVAT platform.

## Bachelor Thesis

**Title:** E ciency Improvement of a Data Annotation Process: Analysis of Optimization Potentials of an Existing Toolchain and Implementation of Selected Measures.
**Author:** Asaad Askar  
**University:** HAW Hamburg

## Overview

The project focused on analyzing an existing data annotation workflow and
adapting CVAT to improve the process.

The work included:

- Analysis and comparison of an existing legacy annotation tool
- Adaptation and extension of CVAT
- Implementation of export/import functionality
- Extension of analysis and monitoring capabilities
- Implementation of a notification system
- Testing and comparison of the resulting workflows

## Technologies

- Python
- Django
- React
- Docker
- ClickHouse
- Webhooks
